# Sprint_7
Финальный проект 7 спринта - Тестирование API учебного сервиса Яндекс Самокат

## Описание проекта
Данный учебный проект содержит автотесты для тестирования  API сайта «Яндекс.Самокат» 

Структура проекта построена с применением Page Object Model:
    - Методы, необходимые для написания тестовых функций находятся в папке methods 
    - Все тестовые функции находятся в папке tests

Вспомогательные файлы
    - файл data.py содержит необходимые url для работы
    - файл generators.py содержит функции генерации данных: курьера для регистрации и генерацию тела заказа
    - в папке tests создан файл conftest.py с фикстурой создания курьера и удаления его из базы данных после завершения тестов
